## Use case

Botfather now features a new "Tools" menu item. Currently, it contains the newly added color picker tool. The tool greatly helps with picking HSV color ranges, which can then be used to isolate color ranges in images. This is useful if you want to find spots of a specific color or color range in an image using the blob detector.
